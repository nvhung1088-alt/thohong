🔑 Cấu Hình Key JSON & 📖 Hướng Dẫn Chi Tiết 4 Bước Lấy Key Google
📖 Hướng dẫn chi tiết 4 bước kết nối Google Indexing API miễn phí (Chỉ làm 1 lần):
  1. Bước 1 - Tạo Project Google Cloud: Truy cập Google Cloud Console ➔ Đăng nhập email Google ➔ Bấm chọn/tạo Project mới (ví dụ đặt tên: Google Indexing Service).
  2. Bước 2 - Bật Web Search Indexing API: Vào thanh tìm kiếm phía trên dán Web Search Indexing API ➔ Bấm chọn dịch vụ ➔ Bấm nút ENABLE (Bật).
  3. Bước 3 - Tạo Service Account & Tải Key JSON: Vào menu IAM & Admin ➔ Service Accounts ➔ Bấm Create Service Account ➔ Sau khi tạo xong, bấm vào tên tài khoản vừa tạo ➔ Sang tab KEYS ➔ Bấm Add Key ➔ Create new key ➔ Chọn định dạng JSON ➔ Bấm CREATE để tải file .json về máy.
  4. Bước 4 - Cấp quyền Owner trong Google Search Console: Mở Google Search Console ➔ Vào Cài đặt (Settings) ➔ Người dùng và phân quyền (Users and permissions) ➔ Bấm Thêm người dùng ➔ Dán email của Service Account (có dạng ... @ ...iam.gserviceaccount.com lấy ở Bước 3) ➔ Chọn vai trò Chủ sở hữu (Owner) ➔ Bấm Thêm.
👉 Bước cuối: Mở file .json đã tải về bằng Notepad/VSCode, copy toàn bộ nội dung dán vào ô bên dưới và bấm nút Lưu Key Google API.
💡 Nhớ cấp quyền Chủ sở hữu (Owner) cho email Service Account trong Google Search Console!
